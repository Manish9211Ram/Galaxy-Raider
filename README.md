# Galaxy Raiders

**Galaxy Raiders** is a high-octane arcade shooter set in the depths of the neon galaxy. Defend your home world from waves of relentless alien invaders using advanced weaponry and power-ups. Now featuring a personalized Login System and Live Leaderboard.

## 🚀 Features

- **Personalized Pilot Profile**: Login with your own Pilot Name to track your stats.
- **Live Leaderboard**: Compete for the top spot! Scores are automatically saved and updated after every game.
- **Neon Cyberpunk Aesthetic**: A vibrant visual overhaul with glowing neon colors and dynamic effects.
- **Neon Time Warp**: Slow down time to dodge impossible bullet patterns (Level 2+).
- **Boss Battles**: Face off against giant, multi-cannon flagships every 3 levels.
- **Power-Up System**:
  - **Shield (Cyan)**: Protects your ship from one enemy hit.
  - **Rapid Fire (Orange)**: Unleash a barrage of lasers with zero cooldown.
- **Progressive Difficulty**: Enemies get faster and more aggressive as you survive longer.

## 🎮 How to Play

### Controls
- **Arrow Keys**: Move Ship Left/Right.
- **Spacebar**: Fire Laser / Launch Game.
- **L**: Open Leaderboard (from Main Menu).
- **Esc**: Go Back / Return to Menu.
- **Shift (Left/Right)**: Activate **Time Warp** (Requires Flux).

### Gameplay
1.  **Login**: Enter your Pilot Name at the start.
2.  **Launch**: Press Space from the Main Menu.
3.  **Survive**: Dodge enemy fire and prevent them from reaching the bottom.
4.  **Warp Time**: In Level 2+, hold Shift to slow down enemies while you move at normal speed. Watch your Flux meter!
5.  **Score**: Defeat the Boss and Aliens to climb the Leaderboard.

## 📥 Installation

### Option 1: Standalone (Recommended)
No installation required!
1.  Navigate to the `dist` folder.
2.  Run **`Galaxy Raiders.exe`**.

### Option 2: Running from Source
1.  **Install Python 3.10+**
2.  **Install Dependencies**:
    ```bash
    pip install pygame-ce
    ```
3.  **Run the Game**:
    ```bash
    python main.py
    ```
