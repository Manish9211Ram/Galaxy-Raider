# Galaxy Raiders

**Galaxy Raiders** is a high-octane arcade shooter set in the depths of the neon galaxy. Defend your home world from waves of relentless alien invaders using advanced weaponry and power-ups.

## Features

- **Neon Cyberpunk Aesthetic**: A vibrant visual overhaul with glowing neon colors (Cyan, Orange, Magenta) and dynamic effects.
- **Neon Time Warp**: Slow down time to dodge impossible bullet patterns (Level 2+).
- **Boss Battles**: Face off against giant, multi-cannon flagships every 3 levels.
- **Power-Up System**:
  - **Shield (Cyan)**: Protects your ship from one enemy hit.
  - **Rapid Fire (Orange)**: Unleash a barrage of lasers with zero cooldown.
- **Progressive Difficulty**: Enemies get faster and more aggressive as you survive longer.
- **Cross-Platform**: Play on Windows, Linux, or deploy to Android!

## How to Play

### Controls
- **Arrow Keys**: Move Ship Left/Right.
- **Spacebar**: Fire Laser.
- **Shift (Left/Right)**: Activate **Time Warp** (Requires Flux).

### Gameplay
1.  **Survive**: Dodge enemy fire and prevent them from reaching the bottom.
2.  **Destroy**: Eliminate all alien waves.
3.  **Warp Time**: In Level 2+, hold Shift to slow downsides enemies while you move at normal speed. Watch your Flux meter!
4.  **Defeat the Boss**: Every 3rd level, defeat the giant Boss ship (Immune to Time Warp).
5.  **Collect**: Pick up power-ups dropped by destroyed enemies to gain an edge.

## Installation

### Windows / Mac / Linux
1.  **Install Python 3.10+**
2.  **Install Dependencies**:
    ```bash
    pip install pygame-ce
    ```
3.  **Run the Game**:
    ```bash
    python main.py
    ```

### Android
This game is ready for Android deployment using **GitHub Actions**.
1.  Push this code to your GitHub repository.
2.  Go to the **Actions** tab in your repository.
3.  Select the **Build Android APK** workflow.
4.  Once finished, download the `galaxy-raiders-apk` artifact.
5.  Install the APK on your Android device.
